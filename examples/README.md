# Examples

Copy-paste **input** configs for the
[Indeed Jobs Scraper](https://apify.com/factden/indeed-jobs-scraper?fpr=factden), plus **illustrative** output rows.

> Output samples (`*.sample.json`) are illustrative of the schema and field shapes — they are not a live capture.
> Real values come from Indeed's public listings at run time. See [../FIELDS.md](../FIELDS.md) for every field.

| File | What it shows |
|---|---|
| `search-salary.input.json` | Keyword + location with the native salary-range filter |
| `remote-recent.input.json` | Remote roles posted in the last 7 days, newest first |
| `lookup-by-jobkey.input.json` | Exact lookup of known jobs by `jobKey` |
| `job.sample.json` | Shape of one Jobs-dataset row |
| `company.sample.json` | Shape of one Companies-dataset row (free) |
